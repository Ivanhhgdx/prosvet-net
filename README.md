# Просвет

[Открыть приложение](https://ivanhhgdx.github.io/prosvet-net/)

«Просвет» помогает понять, похожа ли доступность сайтов через мобильный интернет на работу по белому списку. Проверку выполняет браузер на устройстве. Уровень радиосигнала и наличие глушилки по этой проверке установить нельзя.

## На iPhone

Откройте ссылку в Safari, выберите «Поделиться» → «На экран „Домой“». Запустите приложение с иконки при работающем интернете. В разделе «О методе» раскройте «Как использовать без доступа к сайту» и дождитесь сообщения о готовности. После этого можно запускать сохранённое приложение, даже если сам GitHub Pages недоступен.

Для проверки именно мобильной сети отключите Wi-Fi и VPN. При очень медленном соединении в окне запуска предусмотрено увеличенное время ожидания.

## Как читать результат

Счётчик «Белый список» показывает, сколько из трёх сайтов ответили в каждом замере. Три ответа из трёх возможны и при обычном интернете. Вывод в верхней карточке учитывает также шесть обычных сайтов. Под ним приведены отдельные результаты для российских и зарубежных проектов.

| Проверяемая группа | Сайты |
| --- | --- |
| В опубликованном перечне | Банк России, Почта России, РИА Новости |
| Российские проекты для сравнения | HTML Academy, Linux.org.ru, OpenNET |
| Зарубежные проекты для сравнения | Python.org, W3C, GNU |

Каждый запрос загружает маленькое изображение по HTTPS с уникальным параметром. Успех засчитывается после декодирования и проверки размеров. Вначале выполняются два замера. При непостоянных ответах, слабых данных группы сравнения или отсутствии стабильных ответов из перечня выполняется третий.

Для вывода «Вероятно, включён белый список» пользователь должен подтвердить мобильную сеть без Wi-Fi и VPN, одни и те же как минимум два сайта из перечня должны ответить трижды, а все 18 запросов к обычным сайтам должны завершиться без успешной загрузки. При полном отсутствии ответов приложение оставляет режим неопределённым. По одной выборке нельзя доказать правила конкретного оператора.

Карточка качества показывает медиану длительности успешных загрузок, число неудачных запросов и число тайм-аутов. До 30 завершённых проверок сохраняются в браузере. Приложение не запрашивает геолокацию. При проверке посещаемые сайты получают обычные сетевые запросы.

## Источники

Состав первой группы подтверждают публикации Минцифры о [Почте России и РИА Новости](https://t.me/mintsifry/2713) и [Банке России](https://t.me/mintsifry/2733). Оператор также ведёт [перечень доступных сервисов МТС](https://media.mts.ru/internet/210833-belyj-spisok-interneta). Для сравнения выбраны проекты, не названные в этих публикациях. Состав доступных ресурсов может меняться. Ограничения измерения уровня сигнала описаны в [разъяснении Apple](https://developer.apple.com/forums/thread/721067).
